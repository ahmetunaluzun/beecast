Installing on an Android phone or tablet

Bee Cast is not on Google Play yet. You download the file from this page and install it yourself; Android asks for permission once.

  1. Download the APK

    Open this page on your phone and tap Download the APK. The first time, Chrome asks where to save the file: tap Download. If it warns that the file might be harmful, choose Download anyway.

  2. Open the file

    When the download finishes, "File downloaded" appears at the top of the screen; tap Open next to it. If you miss it, open the Chrome menu (⋮) › Downloads and tap Bee-Cast-Android.apk.

  3. Allow this source

    The first time, Android shows Permission required. Tap Settings and turn on Allow from this source. The phone returns to the installer by itself; if it doesn't, press back.

  4. Install

    Tap Install. If Google Play Protect says "App blocked to protect your device", tap More details, then Install anyway. The warning appears because Bee Cast isn't on Google Play yet and Play Protect doesn't know the developer; not every phone shows it.

  5. Open

    When it says App installed, tap Open. On first launch you pick your language and look, then add your playlist with the details your provider gave you.

Installing on Android TV and Google TV

  1. On the TV, install a downloader app from Google Play (for example Downloader), or copy the file to a USB stick and open it with a file manager.
  2. In the downloader app, enter ahmetunaluzun.github.io/beecast/en/download.html and choose Download the APK.
  3. If the TV asks about unknown apps, allow that app (Settings › Apps › Security & restrictions › Unknown sources).
  4. Install, then Open. Bee Cast works with the remote and appears in the apps row on the home screen.

Installing on Windows

The installer doesn't need administrator rights; Bee Cast is installed for your user account only. It needs Microsoft Edge WebView2: Windows 11 has it built in, and the installer downloads it if it's missing.

  1. Click Download the installer. If your browser says the file isn't commonly downloaded, choose Keep from the menu next to the file.
  2. Open Bee-Cast-Windows.exe. If Windows says "Windows protected your PC", click More info, then Run anyway. The warning appears because the installer doesn't carry a code signature yet.
  3. When setup finishes, Bee Cast is in the Start menu and on the desktop. On first launch you pick your language and look, then add your playlist.
  4. The arrow keys, Enter and Esc work like a remote; you can also click with the mouse and resize the window freely.

In this first Windows version, streams play in the app's built-in player; some movies and channels may use an audio or video format it doesn't support. Wider format support is coming in later versions.

Updating and removing

  • When a new version is out, download it from this page and install it the same way. Your playlists, favourites and settings are kept.
  • To remove it, long-press the app icon › Uninstall. This also deletes Bee Cast's data on the device; you can make a backup first with My devices.
  • On Windows, install the new version over the old one. To remove it, go to Settings › Apps, then Bee Cast › Uninstall; unless you choose to delete the app data in the uninstall window, your playlists and settings stay on the PC.
